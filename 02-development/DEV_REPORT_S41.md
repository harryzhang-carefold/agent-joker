# DEV_REPORT_S41 — 对比页左栏 docx/xlsx 原文不显示修复（全类型真实渲染）

> 章北海（zhangbeihai）| 2026-09-30 | 任务 t_b6df37a8
> 修复对象：用户报「知识库-文档-对比按钮，原文档没有正常显示在页面左侧」。

## 1. 问题根因

`CompareView.vue` 左栏渲染源为 `GET /api/rag/kbs/{id}/docs/{docId}/file`（各类型均 200 正常返回二进制，主 agent 已实测）。
左栏 `loadOriginal()` 的类型分派：
- txt/md → 文本直读高亮（正常）
- png/jpg → `<img>` 直显（正常）
- pdf → `<iframe>` 预览（正常，设计降级无 chunk 高亮）
- **docx/xlsx → 落入 `else` 分支：`leftRendered=false` + 仅一行提示「原文档为 x 类型，当前降级渲染」，原文完全不显示** ← 用户报的问题。

即前端此前对 docx/xlsx **没有做任何真实渲染**，只降级提示。后端解析/切分/存储链路正常（docx 经 python-docx 段落/表格块、xlsx 经 openpyxl 表格块），瓶颈纯在前端展示层。

## 2. 修复方案（仅前端，后端零改动）

新增两个前端依赖（在 `frontend/` 内安装，提交 package.json + package-lock.json）：

| 依赖 | 版本 | 用途 |
|---|---|---|
| `docx-preview` | ^0.4.1 | 将 docx 二进制渲染为 HTML（`renderAsync(blob, container)`） |
| `xlsx`（SheetJS） | ^0.18.5 | 将 xlsx 解析为多 sheet 表格（`XLSX.read` + `sheet_to_json`） |

### 2.1 CompareView.vue 改动
- 左栏模板按 `doc.doc_type` 增补两个分支：
  - **docx** → `<div class="orig-docx" ref="docxRef">`，`renderDocx()` 调 `docx-preview` 的 `renderAsync` 把二进制渲染为 HTML 直接显示。
  - **xlsx** → `<div class="orig-xlsx">` + `<el-tabs>`，`renderXlsx()` 用 SheetJS 解析，**首个 sheet 全量渲染为 HTML 表格，多 sheet 给 tab 切换**。
- 左栏 tag 状态统一：可渲染 = `success`「已渲染」；降级/直显 = `info` 提示；文本类保持「可高亮」。
- 右→左联动（点 chunk）：
  - txt/md 保持按 `char_start/char_end` 精确高亮；
  - **docx/xlsx**：在渲染后的 DOM 里按 chunk 文本做**最佳努力高亮**（新增 `src/utils/highlight.js`：构建「空白归一化」文本流 → `indexOf` 命中 → 跨 text node 用 `<mark class="hl">` 包裹）。匹配不到仅显示原文、不报错（符合任务要求）。
  - pdf/图片：不高亮（设计降级）。
- pdf 保持 iframe；图片保持 img（未改）。

### 2.2 新增 `src/utils/highlight.js`
通用「渲染后 DOM 文本流构建 + 高亮/清除」工具，docx/xlsx 共用，不依赖后端 pos（docx 解析后文本顺序与 chunk 切分顺序一致即可匹配）。
